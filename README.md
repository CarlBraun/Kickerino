## ✨ Features

### 💬 Chat
| Feature | Description |
|---|---|
| **7TV Integration** | Animated & static emotes, badges, colored nicknames (paints) |
| **Green Highlight** | Your nickname mentions glow in the chat |
| **Scrollbar Markers** | Colored stripes for Mentions, Redwords, Timeouts and Bans |
| **Chat History Limit** | Control how many messages are kept (up to 500+) |
| **Pause on Alt** | Freeze chat instantly to inspect a suspicious message |
| **Slow Mode / Queue** | Queue messages so they don't pile up |

### 🛡️ Moderation
| Feature | Description |
|---|---|
| **Easy Moderation** | Ban, Mute, Timeout directly from any message |
| **Custom Mute Duration** | Set exactly how long to mute (e.g. 30 min) |
| **Usercards** | Click any username — see profile, sub status, message history |
| **Redwords List** | Auto-highlight keywords, import from MoKick JSON |

### 🎨 Emotes & Typing
| Feature | Description |
|---|---|
| **Favourite Emotes Bar** | Right-click any emote to pin it above the input field |
| **TAB Autocomplete** | Type `:` or `@` and press TAB to cycle through emotes/users |

### 🎨 Themes
**Dark · White · Amoled (Midnight) · Glass**

### 🔐 Login
**1-Button Browser Login** — opens a browser window, log in with your Kick account and you're done

## 🚀 Getting Started

1. Download `Kickerino.exe` from [Releases](https://github.com/CarlBraun/Kickerino/releases/latest)
2. Run it — no installation needed
3. Click **Login** and sign in via browser
4. Paste any Kick streamer link or type a nickname to open their chat
